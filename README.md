# ElevateNextZA

A responsive starter website for ElevateNextZA, a digital service brand focused on helping small businesses build a professional online presence.

## Website files
- `index.html` — homepage and content
- `style.css` — responsive visual styling
- `script.js` — mobile navigation, year display and contact form behaviour

## Preview locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser.

No build tools or paid software are required.

## Before publishing
- The contact email is currently a placeholder. Replace it with an active address you control in `index.html` and `script.js`.
- Confirm the indicative package prices and project scope before offering them to customers.
- Portfolio tiles are concept demonstrations, not commissioned client projects.
- Add a WhatsApp link only after choosing and approving the number to publish.
- Check all links, wording and contact details on desktop and mobile.

## Free hosting with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and the `/(root)` folder, then save. GitHub will provide the published address after deployment completes.

## Contact form note
The enquiry form opens the visitor's default email application. It does not store or transmit submissions by itself. Configure a working email address before launch.
