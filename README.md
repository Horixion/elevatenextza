# ElevateNextZA

A responsive website for ElevateNextZA, a South African web design service focused on helping small businesses build a professional online presence.

## Website files
- `index.html` — main website and enquiry form
- `style.css` — WhatsApp integration and related styling
- `script.js` — mobile navigation, chatbot and contact form behaviour
- `partner-program/index.html` — partner programme information, referral message templates and a browser-based partner pipeline tracker
- `food-by-shayne/`, `ict-laundry/`, `thabisos-hair-salon/`, `bardeli-concept/`, `jm-truck-trailer/` — independent website concepts and demonstrations

## Partner programme
The partner programme explains how complementary local businesses can make permission-based referrals to one another. It does not promise a fixed number of leads, guaranteed earnings or automatic referral fees. Any referral fee must be agreed in writing before a referral is made.

The tracker on the partner page uses the browser's local storage. Entries stay in that browser and are not sent to GitHub or a server. The page is public and has no login, so do not enter passwords, sensitive information or private customer details. Use the CSV export to back up entries before clearing browser data or switching devices.

## Preview locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser.

No build tools or paid software are required.

## Before publishing or taking on a project
- Confirm that the contact email and WhatsApp number are current and approved for public use.
- Confirm package prices, deliverables, timelines and revision limits in writing before accepting a project.
- Domain names, paid hosting and third-party services may cost extra; disclose those costs before work begins.
- Portfolio pages are independent concepts and demonstrations. They must not be described as commissioned or endorsed client work unless that is true.
- Replace illustrative imagery with properly licensed or client-approved images before commercial launch.
- Get permission before sharing a prospective customer's contact details with a referral partner.
- Check all links, forms and wording on desktop and mobile.

## Hosting
The site is designed for GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and the `/(root)` folder, then save.

## Contact form
The main website enquiry form submits through Formspree. Confirm the Formspree account configuration and test a submission before relying on it for customer enquiries.
